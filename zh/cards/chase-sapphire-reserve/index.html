❓ 常见问题解答

Chase Sapphire Reserve 值得 $550 的年费吗？
如果您使用 $300 的旅行账单抵扣，并且经常乘坐飞机使用 Priority Pass 休息室，实际年费将降至 ~$0–$100。在 Chase Travel 预订可获得 10x 积分，以及 1.5¢/积分的兑换价值，使其成为重度旅行者的顶级选择。但如果您很少旅行，它就是一个昂贵的摆设。
Sapphire Reserve 与 Preferred 相比如何？
Reserve 在 Chase Travel 提供 10x 积分（相比之下为 5x），1.5¢/积分（相比之下为 1.25¢），Priority Pass 休息室，以及 $300 的旅行账单抵扣。Preferred 每年的年费少 $550。如果您每年旅行 6+ 次并使用休息室，Reserve 胜出。否则，Preferred 是更好的选择。
Chase Sapphire Reserve 积分价值多少？
通过 Chase 兑换旅行时每个积分价值 1.5¢，或者兑换 返现 时价值 1¢。对于精明的兑换者来说，转移到 Hyatt、United 和 Singapore Airlines 等合作伙伴，每个积分可以产生 2–3¢+ 的价值。
我可以降级 Sapphire Reserve 吗？
可以，您可以将产品更改为 Chase Sapphire Preferred、Freedom Flex 或 Freedom Unlimited。您将失去休息室使用权和旅行账单抵扣，但可以避免 $550 的年费。注意：如果没有重新申请，您无法再次升级回来。
$300 的旅行账单抵扣会自动生效吗？
是的。它会自动抵扣符合条件的旅行消费（航空公司、酒店、租车、公共交通）。无需注册或通过门户网站预订——只需进行消费，账单抵扣就会在几天内到账。
Priority Pass 在 Reserve 上如何运作？
您将获得 Priority Pass Select 会员资格，您本人和无限量免费同行客人都可无限次使用休息室。大多数其他高级信用卡对每位客人收取 $27+ 的费用。如果您与同伴一起旅行，仅此一项每年就可能价值 $500+。

准备好申请了吗？

申请只需 5 分钟。符合条件的申请人通常会立即获得批准决定。
