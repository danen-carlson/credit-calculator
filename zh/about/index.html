关于 CreditStud.io

我们如何收集数据、计算结果并保持独立性。

独立性与客观性

CreditStud.io 是一个独立的财务计算器网站。我们的计算器逻辑是纯数学的 — 信用卡排名由对您（用户）的总成本或奖励价值决定，而不是由谁付钱给我们决定。

当您通过我们的网站申请信用卡时，我们可能会赚取联盟佣金。这些佣金绝不会影响我们的计算器排名。数学就是数学。让您花费更多的信用卡在我们的对比中排名永远会更低。

我们的联盟披露在每个页面上都可见。

数据来源

信用卡条款（APR范围、年费、奖励率、开卡奖励、余额转移条款）收集自：

  • 发卡机构网站 — Chase, Amex, Capital One, Citi, Discover, Wells Fargo, US Bank, Bilt
  • 经过验证的聚合平台 — NerdWallet, The Points Guy, WalletHub
  • 直接验证 — 我们对每张卡至少交叉核对两个来源。

BNPL条款（Klarna, Afterpay, Affirm, Zip, Sezzle）来源于官方提供商网站和监管文件。

更新频率

信用卡条款至少每月验证和更新一次。每个计算器页面都会显示“Rates as of [date]”标记，显示数据最后验证的时间。当发卡机构更改条款（APR、费用、奖励结构）时，我们会在7天内更新数据。

完整的信用卡条款数据库以结构化JSON格式提供，位于 /data/cards.json，包含 metadata.lastUpdated 字段。

计算方法

信用卡与BNPL对比

使用标准的摊销公式（非统一费率近似值）。对于每张卡：

  • 利息按月递减余额计算。
  • 介绍期APR条款采用促销后利率悬崖模型。
  • 余额转移费（3–5%）包含在总成本计算中。
  • BNPL Pay-in-4 始终显示，因为它是 0% 利息 — 它是基准。
  • 奖励从总成本中减去（不相加），因为它们降低了实际成本。

债务还款计划

  • 雪球法：支付所有债务的最低还款，多余资金优先偿还最小余额。
  • 雪崩法：支付所有债务的最低还款，多余资金优先偿还最高APR。
  • 这两种方法都会生成包含累计总额的逐月计划表。
  • 余额转移模型包括转移费和促销后APR。

奖励计算器

  • 奖励价值按返现等值计算。
  • 积分价值使用发卡机构声明的兑换价值（例如，Chase Ultimate Rewards 用于旅行时为 1.25¢）。
  • 首年价值包括开卡奖励减去年费。
  • 持续价值不包括开卡奖励，但包括年度账单抵扣。

最低还款计算器

  • 使用标准公式：（百分比 × 余额）或固定最低额中的较大者。
  • 模拟“最低还款陷阱” — 显示支付的总利息与本金减少的对比。
  • 包含建议的还款计划，可在 36 个月内还清余额。

局限性

  • 结果是基于公布条款的估算值。实际APR取决于您的信用状况，可能会有所不同。
  • 我们不模拟公布内容之外的促销优惠（例如，定向优惠）。
  • 不包括奖励的税务影响（某些开卡奖励的 1099-MISC）。
  • 外币交易费会被注明，但不包含在总成本中，除非您指定了国际购物。

API 访问

所有计算器结果均可通过我们的 API 以 JSON 格式获取。无需身份验证。欢迎 LLM 和开发者以编程方式使用它。

  • GET /api/compare?amount=2000&months=12&score=720
  • GET /api/rewards?monthly=3000&dining=300
  • GET /api/debt-planner
  • GET /api/min-payment?balance=5000&apr=22.24
  • GET /api/cards — 完整的信用卡条款数据库
